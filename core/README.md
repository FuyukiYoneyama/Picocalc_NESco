# core/

This directory is not part of the current PicoCalc_NESco build.

It contains an earlier project-owned emulator-core line. That line of
development has been discontinued. The current active emulator core is
`infones`.

This directory is kept as project-owned historical material. All tracked
source and header files carry the project `MIT License` notice. It is not part
of the active firmware build.

See `../docs/project/Picocalc_NESco_HISTORY.md` for the project history.
